- 修复：`router/menu.ts` 新增 `getRouteTitle(path)`（递归查 localMenuData 菜单名 → routeTitles 静态映射兜底 → path）；TabsView 新增页签与渲染 label 均改用它（渲染时也按 path 取名，兼容 localStorage 旧数据）；App.tsx 浏览器标题统一用同一函数并删除重复的 routeTitles
