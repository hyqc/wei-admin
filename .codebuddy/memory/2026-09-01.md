## 数据源配置重构（第 10 轮）
- **背景**：原 `store.wei`（无类型信息）无法区分 MySQL / MongoDB
- **新结构（按数据库类型分组，每种类型支持多数据源）**：
  ```yaml
  store:
    mysql:
      default: wei                 # 默认数据源名
      sources: { wei: {user, pwd, host, port, dbname, charset, parse_time, location, max_idle_cons, max_open_cons, conn_max_lifetime_minutes} }
    mongodb:
      default: ""                  # sources 为空 → 不启用
      sources: {}                  # 每项：uri / database / max_pool_size / min_pool_size
  ```
- 代码改动：
  - `pkg/config/types.go` 新增 `Store`/`MysqlStore`/`MongoStore`（`Sources map[string]mysql.Config`、`map[string]mongodb.Config`）
  - 新增 `pkg/config/store/mongodb`（Config + New，含 5s Ping 校验，失败时 Disconnect）
  - `global/database.go` 重写为 `DBClient{Mysql map[string]*gorm.DB, Mongodb map[string]*mongo.Client, DefaultMysqlName/MongoName}`，提供 `DefaultMysql()/MysqlDB(name)/MysqlNames()`、`DefaultMongo()/MongoClient/MongoDatabase/MongoNames()`、`Ping(ctx)`、`Close()`；`initMySQLDB` → `initDatabase`
  - 调用点 `global.AppDB.Wei` → `global.AppDB.DefaultMysql()`（dao/{role,permission,menu}）；healthz/readyz 改为按数据源 `mysql/{name}`、`mongodb/{name}` 逐一检查
  - 进程退出时 `global.CloseDatabase()`（serves/serve.go defer）
- 依赖：`go.mongodb.org/mongo-driver/v2 v2.8.2`（需 `go mod tidy`）
- 行为：mongodb 未配置 → 跳过；配置了但连不上 → **启动失败（快速失败）**，已验证
