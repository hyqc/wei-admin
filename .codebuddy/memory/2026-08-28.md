## admin-vue3x 项目复刻完成（Vue 3 + ant-design-vue）

### 项目概述
- 参考 `admin-frontend`（React + antd）将管理后台复刻为 Vue 3 版本：`admin-vue3x/`
- 技术栈：Vue 3.5 + TypeScript + Vite 6 + Pinia + Vue Router 4 + ant-design-vue 4 + axios
- 开发端口：8000（`vite.config.ts`）；请求 baseURL：`/api`
- Mock 服务：`src/mock/`（Vite 插件 `createMockPlugin` 拦截 /api 请求），通过 `.env` 的 `VITE_USE_MOCK=true` 控制

### 项目结构
- `src/api/`：config.ts（HomePath/LoginPath/AdminId/DefaultModalWidth 等）、request.ts（axios 封装，统一 POST）、pattern.ts（正则）、各模块 API（account/user/role/menu/permission/api）
- `src/store/user.ts`：Pinia 用户状态（menus/permissions 为 map，loginAsync 保存 token）
- `src/router/`：index.ts + menu.ts（动态菜单过滤 HandleRemoteMenuIntoLocal）
- `src/layout/` + `src/components/`：BasicLayout、SiderMenu、HeaderRight、PageContainer、Authorization（权限）、RowEnabledButton
- `src/views/`：login、home（排班日历）、account（个人中心/修改密码）、admin/{user,role,menu,permission,api} 五个系统管理模块
- `src/types/`：与后端接口一一对应的 TS 类型

### 关键约定

### 修复"登录后跳回登录页"的两个关键 bug（本次运行排查）
1. **vue-router 重名路由**：根路由与子路由都命名为 `Home` 导致路由创建失败（白屏）。已将根路由 name 改为 `Layout`（src/router/index.ts）。
2. **Mock 返回的 expire 字段含义**：`GetLoginToken()`（utils/common.ts）用 `now >= obj.expire` 判断过期，其中 expire 被当作"毫秒时间戳"。而 Mock 原先返回 `expire: 604800`（秒数），导致 token 被立即判定过期 → 登录成功后守卫踢回登录页。已改为 `Math.floor(Date.now() / 1000) + 604800`（秒级时间戳，7 天有效）。
   - 注意：SetLoginToken 内部存的是 `expire * 1000`（毫秒），Mock 的 expire 必须是秒级 Unix 时间戳而非时长。

- 修复（对齐 admin-frontend 原版逻辑）：
  1. `src/store/user.ts` `fetchUserInfo()`：改为读取 token 并传 `tokenInfo.remember` 给 `currentAdminInfo`
  2. `src/router/index.ts` `beforeEach`：IsLogin() 且 `Object.keys(store.menus).length === 0` 时 `await store.fetchUserInfo()` 恢复，失败则 Logout 并跳登录页
