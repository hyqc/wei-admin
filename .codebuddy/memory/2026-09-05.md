## 前端表单未校验排查（2026-09-05）
- 现象：个人中心「编辑资料」「修改密码」必填项为空也直接提交到后端。根因：vue3x 两个组件只写了 `:rules` 但**没有 `ref="formRef"`，提交时也没 `formRef.value?.validate()`**，rules 形同虚设。
- 已修：两个组件加 `ref="formRef"` + `onSave` 里先 `await formRef.value?.validate()`（校验失败直接 return，不发请求）；修改密码补了「新密码变化后重新校验确认密码」（对应 react 版的 `dependencies`）。
- **全量排查结论**：vue3x 共 12 处带 rules 的表单，账号/角色/菜单/接口 的 Add/Edit/ResetPassword（8 处）都有 `formRef.value?.validate()`，登录页用 `@finish`（antd 自动校验），**只有个人中心两处缺失**；react 端 11 处含 rules 的表单全部有 `validateFields()` 或用 `onFinish`，无问题。
- 顺手清理：`views/admin/permission/components/common.ts` 的 `DEFAULT_RULES` / `PERMIDDION_RULES` 及 `AdminPerssionKey` import（随 Add/EditPermissionModal 一起已成死代码，双端删除）。
- ✅ **已用 Playwright 跑通端到端验证（13 项全 PASS）**：mock 服务（8010）+ 本机 Chrome（executablePath 绕过浏览器下载失败）。覆盖场景：编辑资料昵称留空/非法邮箱被拦下且不发请求、头像留空仍可提交、修改密码全部留空被拦下（3 个提示）且不发请求、两次密码不一致被拦下、改一致后错误自动消除、合法填写正常提交。
