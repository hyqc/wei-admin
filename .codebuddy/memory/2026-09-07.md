  - 方案：Windows 下 `UTF8 := chcp 65001 >nul &` + `ECHO := $(UTF8)echo`，help 每行用 `@$(ECHO)`；验证手段＝用 .NET Process 以 GBK(936) 解码 stdout，输出"甯哥敤"乱码即证明字节已是 UTF-8（chcp 生效）
